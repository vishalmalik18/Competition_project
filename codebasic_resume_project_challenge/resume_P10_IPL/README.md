# IPL Data Analysis Dashboard (Codebasics Resume Challenge - P10)

## 📌 Project Overview
This project presents a comprehensive analysis of **Indian Premier League (IPL)** cricket data, transformed into an interactive and insightful Power BI dashboard.  
It highlights trends in team performance, player statistics, and season-by-season comparisons, enabling users to quickly uncover patterns and valuable insights from the tournament’s history.  
The dashboard is designed to be visually appealing, easy to navigate, and rich in interactive filters for a personalized exploration experience.

---

## 📂 Repository Contents
- **datasets/** → Contains raw and processed IPL datasets used for analysis.
- **resume project challange 10.pbix** → Power BI dashboard file containing the complete interactive report.
- **resume project challange 10.pdf** → Static PDF export of the dashboard for quick viewing without Power BI.

---

## 📊 Key Features of the Dashboard
- **Season-wise performance analysis** of teams and players.
- **Top-performing players** insights.
- **Win/loss trends** over multiple seasons.
- **Interactive filters** for team, player, and season selection.
- **Visually rich charts** for better storytelling.

---

## 🛠️ Tools & Technologies Used
- **Power BI** → Data visualization and dashboard creation.
- **DAX (Data Analysis Expressions)** → For creating calculated columns, measures, and advanced analytics within Power BI.
